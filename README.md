# SpaceDuck

SpaceDuck это космическая аркада, которая живёт в обычном canvas и собирается в Android APK через Capacitor. Ты играешь за утку, которая летает по Солнечной системе, потом по бесконечному космосу: садишься на планеты, открываешь новые миры, пугаешься чёрных дыр и собираешь ачивки.

## Чем можно заняться

- Летать от планеты к планете, тянуть корабль пальцем как пращу
- Управлять камерой двумя пальцами, чтобы разглядеть, куда ты летишь
- Открывать планеты, звёзды и чёрные дыры, пока они не закончились
- Садиться на все 8 планет Солнечной системы
- Заглядывать к чёрным дырам и возвращаться живым
- Найти TON 618 и проверить, правда ли её так страшно
- Собрать все 22 ачивки
- Создавать свои корабли, помечать любимые, ставить флаги

## Управление

- Потяни вбок и отпусти: утка взлетает и летит по касательной
- Два пальца: пинч-зум, камера приближается и отдаляется
- Палец в полёте: направляешь тягу
- Приземлился: тап по планете и снова в путь
- Кнопка паузы в углу, чтобы выдохнуть

## Ачивки

Первый полёт, Возвращение домой, Первая посадка, Исследователь, Эксперт Солнечной системы, Колонизатор, Посадка на звезду, Край бездны, TON 618, Космический странник, Космический ветеран, Автопилот, Следопыт, Кораблестроитель, Любимец, Бесконечность, Первооткрыватель, Дальнобойщик, Демон скорости, Кругосветчик, Звездочёт, Ныряльщик бездны.

## Как собрать APK

Нужны Node.js, Android SDK и JDK 17+.

```bash
npm install
npx cap sync android
cd android
gradlew assembleDebug
```

APK появится в `android/app/build/outputs/apk/debug/app-debug.apk`, а готовую версию можно скачать из [релизов](https://github.com/Duckerer/SpaceDuck/releases).

## Структура

```
www/        сама игра: js, css, html
android/    Android-обёртка Capacitor
```

## Технологии

- HTML5 Canvas для отрисовки
- Чистый JavaScript без зависимостей
- Capacitor для Android-сборки
- WebAudio для звука, вибрация на телефоне

Сделано с любовью к уткам и космосу.
